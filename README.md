# Lung Cancer Prediction using Machine Learning

## Project Overview

This project aims to predict lung cancer using machine learning models. It uses a dataset of patient information and applies various classification algorithms, including Logistic Regression, Decision Trees, Support Vector Machines, K-Nearest Neighbors, Naive Bayes, Random Forests, and Convolutional Neural Networks (CNNs), to build a predictive model.

## Dataset

The dataset used in this project contains information about patients, including their age, gender, smoking habits, and other relevant features. The target variable is the presence or absence of lung cancer.

## Methodology

1. **Data Loading and Preprocessing:** The dataset is loaded and preprocessed, including handling missing values and removing unnecessary columns.
2. **Data Visualization:** The data is visualized to understand the distribution of the target variable and the relationships between features.
3. **Model Training:** Different machine learning models are trained on the dataset using appropriate algorithms.
4. **Model Evaluation:** The trained models are evaluated using metrics such as accuracy, confusion matrix, and ROC curve.
5. **Model Selection:** The best performing model is selected based on the evaluation results.

## Results

The results of the project demonstrate the effectiveness of machine learning in predicting lung cancer. The selected model achieves a high accuracy score and provides insights into the important features for prediction.

## Usage

To run this project, follow these steps:

1. Clone the repository.
2. Install the required libraries.
3. Load the dataset.
4. Train and evaluate the models.
5. Analyze the results.
